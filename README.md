## TaskHive Studio — my own products

Side projects ship under TaskHive Studio, my own (unregistered) studio. Their code lives in private repos; both apps are released on the Play Store.

### YaarCast — social media platform designed for India (actively in development)

A social media platform designed for India. Actively in development — currently my main side project. Also released on the Play Store.

- React Native / Expo Android app with Supabase Auth, PostgreSQL, private Storage and Edge Functions
- Invitation-based access, friend-approved private feeds, communities, private messages, moderation and account deletion

### Guru Z — offline Android classroom management

An offline Android teaching register for independent tutors, trainers and instructors, in English and Bengali. Released on the Play Store.

- Per-class fees, attendance and reports in Bengali and English
- Students, class schedules, attendance and fees together on the teacher's phone — no account, advertising, tracking SDK or hosting required

### TaskHive Studio POS — multi-tenant point of sale & inventory

A commercial, multi-tenant Point of Sale and Inventory Management suite: a .NET Web API backed by MySQL, plus a React cashier client.

- Cashier terminal, inventory with immutable stock ledger, analytics dashboard, catalogue, receipts
- Every workspace (shop) isolated at the database query level; JWT sessions, role gates (Owner/Manager/Cashier)
